## Introduce

개발하며 겪은 경험과 배움을 [블로그](https://jeongseonghun.com)에 기록하고, 회고와 공유를 통해 더 단단한 개발자로 나아가고자 합니다.

최근에는 AI 에이전트와 여러 프로젝트를 만들며, 더 생산적으로 일하면서도 원하는 결과물을 얻는 방법을 실험하고 있습니다.
구현부터 디자인까지 직접 살펴보며, 결과물을 판단하고 다듬는 감각을 키우고 있습니다.
